EXAM DOSMAN v2.8.1 - What's New (Hotfix & Semi-Offline Exam Mode):

- Fixed HTML question/option parser bug where nested <div> blocks (such as Economics transaction lists or Chemistry MS Word WordSection1 options) could truncate questions or nest option cards vertically.

- Guided Access Protection: exiting Guided Access during an active exam without entering the exit password will trigger exam lock protection.
- Exit password is now also required when logging out from the student course dashboard.
- Added completed quiz attempt count and submitted grade status badge on course and quiz cards.
- Improved question layout, option spacing, bottom question-number navigation bar, keep-screen-awake during exams, and full student name/class display.
